Panduan Penggunaan Evaluasi SMP

1. Lengkapi Identitas Sekolah

Buka tab Identitas Sekolah dan isi nama sekolah, NIP guru, serta NIP Kepala Sekolah. Data ini otomatis tersusun pada KOP resmi dan format Tanda Tangan seluruh dokumen.

2. Buat Paket Soal via Generator AI

Pilih Mata Pelajaran, Jenjang Kelas, Lingkup Materi, dan jumlah butir soal PG/Essay. Klik tombol Generate untuk mengolah perangkat evaluasi secara otomatis.

3. Cetak PDF & Unduh Word (.doc)

Gunakan tombol Cetak PDF / Print pada header kanan atas untuk mencetak dokumen format kertas A4/F4 resmi tanpa bagian navigasi aplikasi. Anda juga dapat mengunduhnya dalam format Word editable.

Pengaturan Gemini API Key

Aplikasi ini mendukung penyusunan soal cerdas via Google Gemini API. Masukkan API Key Anda di bawah (opsional). Jika dikosongkan, generator akan menggunakan mesin pembuat soal standar otomatis.
