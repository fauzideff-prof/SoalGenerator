Panduan Penggunaan Aplikasi Evaluasi SMP

1

Atur Identitas Sekolah

Buka menu Identitas Sekolah dan lengkapi nama sekolah, nama guru, NIP, serta nama Kepala Sekolah agar tercetak otomatis di Kop Surat.

2

Isi Form Generator Soal

Pilih mata pelajaran (terseedia 20+ mapel SMP/MTs), masukkan materi pokok, CP, TP, serta variasi jumlah soal dan tingkat kognitif.

3

Generate Perangkat Otomatis

Klik tombol Generate. Aplikasi menyusun Naskah Soal, Kisi-Kisi, Kartu Soal per Butir, dan Kunci Jawaban sekaligus.

4

Cetak atau Ekspor Dokumen

Gunakan tombol cetak untuk menyimpan sebagai PDF standar A4 formal Times New Roman 12pt siap pakai.

Pengaturan Gemini API Key

Aplikasi ini mendukung pembuatan soal cerdas secara otomatis via Google Gemini API. Masukkan API Key Anda di bawah (opsional). Jika dikosongkan, generator akan menggunakan fallback template internal.
